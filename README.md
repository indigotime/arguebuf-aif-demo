# Argdown to AIF conversion demo

Using Arguebuf-typescript - a TypeScript library for dealing with argument graphs.

Using modified version of OVA3 - the latest release of the Online Visualisation of Argument analysis tool.

# Usage

1. Download the repository as a ZIP file and extract it.
2. Open aif-test.html in a web browser to try the ArgDown-to-AIF conversion demo. Paste valid ArgDown text and run the conversion.
3. Open analyse.html to visualize arguments. Load an ArgDown or AIF file to view its argument map.
